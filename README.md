# Демонстрация ООП на C#: класс NumberBox

Учебное консольное приложение по дисциплине «Объектно-ориентированное программирование».

## Цель работы

Создать консольное приложение, демонстрирующее работу основных элементов класса в C# и закрепляющее понимание базовых принципов объектно-ориентированного программирования.

## Условие задачи

Программа работает с целочисленным массивом размерности `n`.

Элементы массива формируются по формуле:

```text
a[i] = ±(i + 1)², где i = 0, 1, ..., n - 1
```

Знак каждого элемента определяется случайно с одинаковой вероятностью.

Программа:
- создаёт и выводит массив;
- находит количество положительных элементов;
- находит первый и последний отрицательные элементы;
- вычисляет сумму элементов между первым и последним отрицательными;
- возвращает `0`, если отрицательных элементов меньше двух.

## Класс NumberBox

В проекте реализован класс `NumberBox`:

- `private int[] numbers` — закрытое поле для хранения массива;
- `NumberBox(int n)` — конструктор, создающий и заполняющий массив;
- `PositiveCount` — свойство только для чтения, возвращающее число положительных элементов;
- `ShowNumbers()` — метод вывода массива;
- `SumBetweenNegatives()` — метод вычисления суммы между первым и последним отрицательными элементами.

## Запуск проекта

### Через Visual Studio Code

1. Открыть папку проекта в VS Code.
2. Открыть встроенный терминал.
3. Выполнить команду:

```bash
dotnet run
```

### Через Visual Studio

1. Открыть файл проекта с расширением `.csproj`.
2. Нажать `F5` или кнопку Start.
